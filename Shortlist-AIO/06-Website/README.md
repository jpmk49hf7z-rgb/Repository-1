# Shortlist AIO — marketing site

> **Do you need to touch this? Only to deploy it.** I maintain the content. Your
> one job is the deploy, and only after the legal review is back — the build
> deliberately refuses to publish while the privacy policy or terms still carry
> unfilled placeholders or notes to counsel.

Static site. No build step for the home page; the two legal pages are
generated from `../03-Legal-For-Review/*.md` so the published policy and the reviewed
document cannot drift apart.

## Build

```bash
python build.py
```

Regenerates `privacy.html` and `terms.html`. The build **exits non-zero and
refuses to publish** while either page still contains an unfilled `[BRACKET]`
placeholder or an internal note to counsel. That is deliberate: a privacy
policy that ships with "[COUNSEL] confirm this is enforceable" still in it is
worse than no policy at all.

Currently failing by design. It will pass once the entity name, address,
domain, and effective dates are filled into `../03-Legal-For-Review/`.

## Deploy

Cloudflare Pages, free tier:

1. Connect the repository, set the build output directory to `site/`.
2. Build command: `pip install markdown && python build.py`
3. Point the apex domain at it.

The failing build is a feature here — Pages will refuse to deploy an
unfinished policy.

Netlify and GitHub Pages work identically. Do not use the primary domain for
cold outbound; see `../04-Setup-Guides/EMAIL-INFRASTRUCTURE.md` §1.

## Design

One stylesheet, `styles.css`, shared by the site and echoed in the client
report generated by the scanner. Newsreader for display, IBM Plex Sans for
text, IBM Plex Mono for data. Light and dark both defined at token level.

The share-of-voice bars on the home page are the same visual device the
report uses — the site shows the product's own output rather than describing
it, which is the only demo that matters here.

## Content notes

The home page deliberately states what we **will not** promise, and publishes
the measurement method. In a category where the standard pitch is a
guaranteed citation rate, refusing to make that claim is the differentiator,
not a weakness. Do not let this drift toward guarantee language.
